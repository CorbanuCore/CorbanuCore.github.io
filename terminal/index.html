How we tested

  • Run on 24 September 2026 with Corbanu 0.1.47, Claude Code 2.1.281 and Hermes v2026.9.24.
  • Each run starts in a fresh, sealed container. The grading tests are never in the prompt or the workspace.
  • Every agent used OpenRouter, pinned to the same host (Google for Opus 5.5, Moonshot for Kimi K3), with reasoning set to high.
  • Cost is the amount OpenRouter billed. Time is wall-clock time per task, averaged over all runs.

02 / WHY

Less wasted work.

Fewer model calls

Corbanu gets the job done in fewer round trips: 6.4 calls per task on Opus 5.5, against 7.3 for Claude Code and 9.0 for Hermes. Fewer calls means less time and a smaller bill.

Any model

Run Claude, GPT, Kimi, GLM or DeepSeek through OpenRouter, Vercel or your own provider keys. Pick a different model for each agent.

Open source

Apache-2.0 and written in Rust, built on the Codex CLI runtime. Read the code.

> Invoke-RestMethod https://github.com/CorbanuCore/CorbanuTerminal/releases/latest/download/install.ps1 | Invoke-Expression

Use the native PowerShell installer. PowerShell's curl alias is unsupported.
