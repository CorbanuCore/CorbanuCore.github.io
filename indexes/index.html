One idea. Two runs. One valid result.
The interface keeps product creation simple without weakening the proof. Every choice that changes a constituent or weight is bound before execution.

        

          
01 / FREEZE
Turn the phrase into a contract
The mandate, universe, weighting rule, relevance floor, rebalance schedule, exact model, and runtime profile receive one request hash.

          
02 / EXECUTE
Score and weight the universe
The admitted model scores each eligible company against the same mandate. The selected rule converts qualifying names into integer weights.

          
03 / REPLAY
Accept only an exact match
An independent run must reproduce the scoring artifact byte for byte and rebuild the same weights. A mismatch leaves the index invalid.
